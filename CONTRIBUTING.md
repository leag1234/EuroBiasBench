# Contributing to EuroBiasBench

We welcome issue reports, methodological critiques, improvements to prompt pairing and EU-law source verification, and reproducibility fixes.

1. Open an issue describing the measurement risk, affected scenario IDs and proposed change.
2. Submit small pull requests with tests. Do not modify historical evaluation responses after generation.
3. Keep research prompts free from private data and avoid introducing political stance as an answer key.
4. For legal claims, cite primary EU sources and explain temporal and jurisdictional scope.
5. New dataset cases should contain a valid paired contrast, explicit intended behavior, and links to authoritative sources.
6. Do not claim that model provenance guarantees a particular bias, or that AI judge ratings are scientifically validated.

This code is Apache-2.0. Model checkpoints, external datasets and provider services have their own licenses.
